# TWIN — Devanjana's personal website

A creative, editorial-style personal website built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation and small reveal interactions

## Before publishing

Personalise the interests and introduction with details Devanjana is happy to share. Add a real contact address to the email link if she wants one displayed.

No build step or framework is required.
